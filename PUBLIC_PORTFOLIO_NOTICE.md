# Public Portfolio Notice

This repository is a sanitized portfolio copy of an internship prototype for visitor and temporary-access management.

- Demo/synthetic records only.
- No production customer, employee, visitor, or organizational data is included.
- Local demo credentials shown in the README are intentionally seeded test accounts, not real credentials.
- The runtime SQLite database and generated signing secret are intentionally excluded from version control.
- Production deployment would require approved identity, security, privacy, infrastructure, retention, and access-control integrations.
