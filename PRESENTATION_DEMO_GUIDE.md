## 4. Demonstrate host approval / pre-registration

- `host.it`
- `Host@123`

Open **Pre-Register Visitor**.

Explain:

- host can search existing visitor profiles with masked phone numbers;
- host can pre-register only for themselves and their own department;
- a host cannot see another visitor’s full history;
- the employee’s pre-registration acts as host approval, but security still verifies the person at the gate.

## Closing line

> “SecurePass does not replace the security guard. It replaces repetitive paper record-keeping and gives security a faster, searchable and auditable visitor process from arrival to exit.”
